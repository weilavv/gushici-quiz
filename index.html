使用说明

  1. 首页选择练习范围：全部题库、按知识点、或者随机组卷（可限时）。
  2. 答题页点选项即判分，显示正确答案与解析；可随时用答题卡跳题。
  3. 错题本自动收集答错的题目，可反复重做；清空按钮在错题本页面右上角。
  4. 进度保存在浏览器本地（localStorage），换设备或清缓存会丢失。
部署方式：本页为纯静态单文件，可直接双击打开；放到 GitHub Pages / Gitee Pages / 任意静态托管即获得公开链接。

部署到 GitHub Pages（5 步）

步骤操作
1注册 GitHub，新建仓库，例如 guoxue-quiz
2把本文件（index.html）上传到仓库根目录
3仓库 Settings → Pages → Source 选 main 分支、/root
4等待 1–2 分钟，访问 https://你的用户名.github.io/guoxue-quiz/
5更新题库：替换文件后重新上传，刷新即可
国内访问慢可改用 Gitee Pages 或腾讯云静态托管，步骤相同。
